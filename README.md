Библиотечная система:
Проект представляет собой систему управления библиотекой с каталогизацией книг, учетом читателей, выдачей и возвратом литературы.

Основные функции:

Каталогизация книг: Управление книгами, авторами, жанрами

Учет читателей: Регистрация, управление активностью читателей

Выдача/возврат книг: Учет выдачи, расчет штрафов за просрочку

Поиск: Расширенный поиск книг по названию, автору, жанру, ISBN

Статистика: Аналитика библиотеки (популярные жанры, авторы и т.д.)

Многопоточность: Асинхронная обработка операций
